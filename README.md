📘 IG Bank – Sistema de Login

Um sistema de login fictício desenvolvido para a disciplina de Interação Humano-Computador, com foco em usabilidade, experiência do usuário e validação local, funcionando totalmente offline.

📌 Descrição do Projeto

O IG Bank é uma simulação de sistema de login bancário, criado para demonstrar princípios de usabilidade, estética e interação digital.
O sistema não utiliza banco de dados e toda a validação acontece localmente no navegador, garantindo um funcionamento simples, rápido e totalmente offline.

Ele apresenta:

Interface moderna e responsiva

Design esteticamente agradável

Validação local de e-mail/CPF e senha

Feedback visual e textual imediato

Microanimações para melhorar a experiência

Facilidade de uso e clareza na navegação

🎯 Metas de Usabilidade (Obrigatórias) — Análise
✔ Fácil de lembrar como usar

A interface segue o padrão clássico de login: campos claros, ícones intuitivos e fluxo simples.
O usuário só precisa digitar e confirmar — fácil de repetir futuramente.

✔ Fácil de entender

Labels, placeholders e ícones explicam sozinhos o que o usuário deve fazer.
Todos os campos são autoexplicativos e possuem foco visual ao clicar.

✔ Útil

O sistema cumpre a função esperada: permitir o usuário simular um login funcional, com validação real.

✔ Seguro (percepção do usuário)

Ícones de cadeado

Mensagem de “Ambiente Criptografado e Seguro”

Senha com caracteres ocultos

Layout confiável, tons escuros e design consistente

Tudo contribui para a sensação de segurança.

✔ Eficiente

O fluxo é direto: 2 campos e 1 clique.
A validação ocorre instantaneamente, sem recarregar a página.

🌟 Metas de Experiência — Análise

As metas escolhidas (mínimo 5) foram atendidas da seguinte forma:

⭐ Esteticamente apreciável

Glass effect, sombras suaves, espaçamento harmonioso, tipografia moderna e ícones bem aplicados tornam a interface visualmente marcante.

⭐ Agradável

Animações leves, cores equilibradas e feedbacks amigáveis deixam o uso confortável.

⭐ Interessante

A ideia de um banco fictício, com identidade visual própria, desperta curiosidade e engaja o usuário.

⭐ Motivador

Ao logar corretamente, o usuário recebe feedback positivo reforçando a ação correta.

⭐ Emocionalmente adequado

Cores fortes e confiáveis reforçam a sensação de segurança, essencial em sistemas bancários.

⭐ Satisfatório (extra)

O sistema responde rapidamente e confirma a ação do usuário, trazendo sensação de conclusão bem-sucedida.
